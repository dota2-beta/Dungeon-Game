# Dungeon Crawler (Microservices Architecture)

Это распределенная версия пошаговой игры в жанре "исследование подземелий" (Dungeon Crawler).
Проект представляет собой переход от монолитной архитектуры к микросервисной при помощи gRPC и Kafka.

Данный проект является **архитектурным прототипом**.
Его основная цель — демонстрация работы микросервисной архитектуры (Spring Boot, Kafka, gRPC, Redis)

**Текущие ограничения:**
1.  **Упрощенный геймплей:** реализованы только базовые механики (перемещение, атака, простой AI). Отсутствуют сложные системы (например, механики способностей).
2.  **Жизненный цикл:** не реализована логика автоматической очистки устаревших данных.
3.  **Безопасность:** отсутствует слой авторизации/аутентификации. Идентификация пользователей происходит упрощенно.
## Архитектура

Система построена на базе **C4 Model** и состоит из трех основных микросервисов:

1.  **WebSocket Service:**
    *   Точка входа для клиентов.
    *   Управляет WebSocket-соединениями (STOMP).
    *   Маршрутизирует команды в игровые сервисы.
2.  **Game Session Service:**
    *   Управляет жизненным циклом сессии (хранение состояния в **Redis**).
    *   Содержит игровой движок (перемещение, бой, механики).
    *   Реализует AI монстров.
3.  **Game Data Service:**
    *   Хранит баланс и шаблоны (PostgreSQL).
    *   Загружает данные из YAML.
    *   Кэширует данные для быстрого доступа.

## 🎮 Функционал

*   **Пошаговая система**
*   **Гексагональная карта:** перемещение и взаимодействие с объектами.
*   **Боевая система:**
    *   Очередность ходов.
    *   Очки действия (AP).
    *   AI противников (поиск пути и выбор цели).
    *   Возможность мирного соглашения (голосование).

## 🛠️ Технологический стек

### Бэкенд (Java 17 & Spring Boot 3)
*   **Communication:**
    *   **gRPC (Protobuf):** синхронное взаимодействие между сервисами.
    *   **Apache Kafka:** асинхронная шина событий (Event Bus).
    *   **WebSocket (STOMP)**
*   **Data & Persistence:**
    *   **PostgreSQL:** хранение статических данных (шаблоны игроков/монстров).
    *   **Redis:** хранение состояния игровых сессий.
    *   **Spring Data JPA / Redis.**
*   **Tools:** Gradle, Lombok, MapStruct.

### Фронтенд
*   **React 18** + **TypeScript**.
*   **Vite** — сборка.
*   **SVG** — рендеринг игровой карты.
*   **StompJS** — взаимодействие с сервером.

### Infrastructure & DevOps
*   **Docker & Docker Compose**.
*   **Nginx**

## 🚀 Как запустить (Getting Started)

Для запуска требуется только **Docker Desktop**. Вам не нужно устанавливать Java, Node.js или базы данных локально.

1.  **Клонируйте репозиторий:**
    ```bash
    git clone https://github.com/dota2-beta/Dungeon-Game.git
    ```

2.  **Переключитесь на ветку с микросервисами:**
    ```bash
    git checkout feature/microservices-architecture
    ```

3.  **Запустите проект одной командой:**
    ```bash
    docker-compose up --build
    ```
    *Процесс первой сборки может занять некоторое время.*

4.  **Играйте!**
    *   Откройте браузер по адресу: **`http://localhost:3000`**
